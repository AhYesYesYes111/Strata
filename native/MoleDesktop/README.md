# Strata

Strata 是一个独立的 SwiftUI 原生 macOS 磁盘工具。界面、地球插画和图标均为独立实现，设计参考了 [Mole Mac 的公开功能展示](https://mole.fit/)。清理和维护使用随应用打包的 Mole CLI 脚本。[许可证与项目归属](../../LICENSES.md)

## 构建和启动

在 macOS 上安装含 macOS 26 或更新 SDK 的 Xcode 开发工具与 Python 3，从仓库根目录运行：

```sh
python3 native/MoleDesktop/build.py
open native/MoleDesktop/build/Strata.app
```

构建脚本调用本机 Swift 编译器，同时生成可解压运行的 `build/Strata.zip`。目标系统为 macOS 13 或更新版本，二进制架构随构建用 Mac 而定。应用使用本地临时签名。

## 使用

右上角的地球按钮可选择简体中文、English 或跟随系统。语言选择会保存，切换时可留在当前目录或保留本次扫描和筛选。报告中的原始 Mole 运行记录及文件路径按原文显示。

点右上角「授权」直接进入 macOS 的「完全磁盘访问权限」。要测量受保护的文件夹，请先在磁盘分析中主动选择它。macOS 要求额外权限时，可在系统设置中管理。如果列表里没有它，可从应用的权限面板定位正在运行的副本，再通过系统的「＋」添加。⌘, 可随时打开权限说明，也可从这里进入「文件与文件夹」和「自动化」的系统设置。查看系统状态和应用列表使用普通权限即可。macOS 负责显示实际授权状态和确认开关。

- **空间清理**先运行 `mo clean --dry-run`。扫描前显示扫描与清理各自的粗估时长。执行期间显示当前项目、已用和预计剩余时间。本机会根据最近一次成功执行的同类任务及其阶段耗时更新估算。等待审阅和确认的时间排除在估算之外。「查看明细」支持用 ⌘F 搜索路径、分组和运行记录，用 ⌘S 将本次载入的报告导出为 UTF-8 文本。筛选只影响显示。当预览有可核对的清单和空间估算时，可以从明细页确认执行整轮 `mo clean`。引擎会重新核对候选项和保护规则，默认会永久清理符合条件的内容，包括个人废纸篓。已有管理员授权可能扩大执行范围。
- **应用**可以按名称搜索、按位置筛选、查看版本，以及在访达中定位。
- **维护**运行 `mo optimize --dry-run`，展示建议、跳过原因和失败项目。
- **磁盘分析**首次打开时从启动磁盘根目录开始。面积图随 Users、Applications、Library 等目录的测量进度更新。已测文件占用和 macOS 报告的整卷已用空间分别显示。扫描覆盖启动盘的系统卷和数据卷，跳过重复挂载路径及外接卷。自动分析也会跳过桌面、文稿、下载、照片图库等隐私位置。点击「选择后测量」，在系统选择器里确认后即可单独分析该位置。点击文件夹可逐层进入，顶部路径可返回任意上级。「位置」菜单也可选择个人文件夹或其他目录。权限不足或达到扫描上限时，已测得的部分容量以 ≥ 标记。
- **状态**以八张卡片显示资源健康评分、各核心 CPU 负载、GPU 使用率、内存压力与交换量、电池、磁盘、网络和风扇。点 CPU 柱图可切换为一分钟趋势。传感器可用时显示温度、GPU 功耗、风扇转速与调速模式、电池健康与循环次数、启动盘读写速率和 Wi-Fi 信号强度。评分根据当前可读取的指标估算。可用磁盘空间采用 macOS 为重要操作提供的容量估算，包含可回收空间。
- **进程表**支持搜索名称或 PID，点击列标题可按内存、CPU、估算功耗或 PID 排序。每个进程的 CPU 以一个核心为 100%，功耗来自内核归属的 CPU 能量变化，单位为瓦。仅允许读取驻留内存的进程标记为 RSS。传感器或计数器不可读取时显示「—」。状态页活跃时每两秒采样硬件，每三秒更新进程。

- **菜单栏**在 Strata 运行时显示行星图标。点击图标可查看健康评分、硬件读数、电池和占用最高的五个进程。点击「内存」或「CPU」可切换进程排序，点击健康评分可打开主窗口的「状态」页。关闭主窗口后仍可使用菜单栏。要完全退出，请在面板底部点击「退出 Strata」，或在主窗口按 ⌘Q。菜单面板和状态页共用采样，两处都收起时暂停刷新。

界面使用石墨灰底色和薄荷色主按钮。首页使用一张随包提供的 1254 × 1254 透明地球图，轨道和扫描线由 SwiftUI 绘制。顶部导航按窗口中心布局，⌘1 至 ⌘5 切换页面。macOS 26 及以上使用系统 Liquid Glass，早期系统使用系统材质。导航响应「减少透明度」，窗口动画遵循「减少动态效果」。

Mole 预览和执行沿用当前用户的白名单及操作日志。实际清理需要在窗口中确认。风扇转速和调速模式以只读方式显示。

## 验证清理确认流程

```sh
python3 native/MoleDesktop/Tests/test_cleanup.py
```

此测试创建隔离的临时应用包与用户目录，用记录参数的模拟 CLI 验证预览、确认、取消、重复执行保护，以及耗时估算的保存、重估和失效。

新增磁盘与监控回归可在本机运行：

```sh
python3 native/MoleDesktop/Tests/test_monitoring.py
```
