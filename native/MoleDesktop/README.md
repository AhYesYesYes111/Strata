# Strata

Strata 是一个独立的 SwiftUI 原生 macOS 磁盘工具。应用随包附带此仓库的 [Mole 开源 CLI](https://github.com/tw93/Mole)，使用 GPL-3.0 许可证。界面、地球插画和图标均为独立实现。界面设计参考 [Mole Mac 公开功能展示](https://mole.fit/)。

## 构建和启动

在 macOS 上安装含 macOS 26 或更新 SDK 的 Xcode 开发工具与 Python 3，从仓库根目录运行：

```sh
python3 native/MoleDesktop/build.py
open native/MoleDesktop/build/Strata.app
```

构建脚本调用本机 Swift 编译器，同时生成可解压运行的 `build/Strata.zip`。目标系统为 macOS 13 或更新版本，二进制架构随构建用 Mac 而定。应用使用本地临时签名。

## 使用

右上角的地球按钮可选择简体中文、English 或跟随系统。语言选择会保存，切换时可留在当前目录或保留本次扫描和筛选。报告中的原始 Mole 运行记录及文件路径按原文显示。

点右上角「授权」直接进入 macOS 的「完全磁盘访问权限」。需要分析受保护目录时，在系统设置中启用 Strata。如果列表里没有它，可从应用的权限面板定位正在运行的副本，再通过系统的「＋」添加。⌘, 可随时打开权限说明，也可从这里进入「文件与文件夹」和「自动化」的系统设置。查看系统状态和应用列表使用普通权限即可。macOS 负责显示实际授权状态和确认开关。

- **空间清理**先运行 `mo clean --dry-run`。扫描前显示扫描与清理各自的粗估时长。执行期间显示当前项目、已用和预计剩余时间。本机会根据最近一次成功执行的同类任务及其阶段耗时更新估算。等待审阅和确认的时间排除在估算之外。「查看明细」支持用 ⌘F 搜索路径、分组和运行记录，用 ⌘S 将本次载入的报告导出为 UTF-8 文本。筛选只影响显示。当预览有可核对的清单和空间估算时，可以从明细页确认执行整轮 `mo clean`。引擎会重新核对候选项和保护规则，默认会永久清理符合条件的内容，包括个人废纸篓。已有管理员授权可能扩大执行范围。
- **应用**可以按名称搜索、按位置筛选、查看版本，以及在访达中定位。
- **维护**运行 `mo optimize --dry-run`，展示建议、跳过原因和失败项目。
- **磁盘分析**打开时扫描个人文件夹。右侧色块的面积表示已测得的分配空间。单击文件夹色块可逐层进入，点击上方路径可返回任意上级。左栏可按名称、类型和占用查找当前目录项目。「位置」菜单可切到启动磁盘的数据卷或其他文件夹。权限与扫描上限会产生部分结果，APFS 克隆可能共享物理数据块。
- **状态**用不同尺寸的卡片显示芯片、热状态、运行时间、CPU 与内存趋势、电池、可用空间，以及主网络接口的收发速率。状态页活跃时每两秒采样一次，曲线保留最近 60 秒。

界面使用石墨灰底色和薄荷色主按钮。顶部导航按窗口中心布局，⌘1 至 ⌘5 切换页面。macOS 26 及以上使用系统 Liquid Glass，早期系统使用系统材质。导航响应「减少透明度」，窗口动画遵循「减少动态效果」。

Mole 预览和执行沿用当前用户的白名单及操作日志。实际清理需要在窗口中确认。软件卸载、风扇控制和菜单栏监控未包含在此版本中。

## 验证清理确认流程

```sh
python3 native/MoleDesktop/Tests/test_cleanup.py
```

此测试创建隔离的临时应用包与用户目录，用记录参数的模拟 CLI 验证预览、确认、取消、重复执行保护，以及耗时估算的保存、重估和失效。
